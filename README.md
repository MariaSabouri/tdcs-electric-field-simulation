# tDCS Electric Field Simulation and Literature Review

A biomedical engineering project focused on transcranial direct current stimulation (tDCS), electric field simulation, and a literature review of brain stimulation and retinal prostheses.

## Project Overview

Conducted as part of an undergraduate course project in December 2024, in a team of three.

The project involved simulating electric fields using SimNIBS and FreeSurfer with an MRI-derived head model. Two electrode configurations were investigated: rectangular gel electrodes and elliptical electrodes. The simulation results were compared with those reported in a reference publication.

The project also included a literature review of retinal prostheses, including Argus II, and brain stimulation techniques such as deep brain stimulation (DBS), transcranial magnetic stimulation (TMS/rTMS), electroconvulsive therapy (ECT), and vagus nerve stimulation (VNS).

## Tools and Technologies

- SimNIBS 4
- FreeSurfer
- MRI-derived head modeling
- Electric field simulation
- Literature review
